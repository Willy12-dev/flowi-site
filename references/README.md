# References folder

Drop reference images here. I read them, study the format, and update the
carousel generator templates accordingly. **Not committed to git** — see the
.gitignore at the bottom.

## Where to drop what

| Folder | What goes here |
|---|---|
| `ugwusmate/` | Anything from @ugwusmate (or similar dev-reference accounts) |
| `therapist-advice/` | Therapist channels, mental health advice carousels, signs-you-have-X format |
| `dev-content/` | Other coding/AI/tech content references |
| `trading-content/` | Trader psychology, market analysis carousels, "Dear new trader" posts |
| `dear-x-letters/` | "Dear son", "Dear younger self", "Letter to my X" format posts |
| `viral-formats/` | Anything that converted hard but doesn't fit a category yet |
| `quotes-philosophy/` | Stoic posts, single-quote slides, philosophy carousels |
| `unsorted/` | Just drop anything here if unsure. I'll sort and tell you what category. |

## How to use this with me

1. Drop images into a folder (any format: PNG, JPG, JPEG, WEBP)
2. Tell me: **"study the new references in &lt;folder&gt;"** or **"study references unsorted"**
3. I list the folder, read each image, synthesize the patterns
4. I update the carousel generator templates if a new format emerges
5. I optionally write findings to `references/SYNTHESIS.md`

## What I look for in each reference

- **Visual treatment** — background, type, color palette, accent
- **Layout** — text position, image position, white space ratio
- **Hook style** — cover slide curiosity gap pattern
- **Body content density** — how much text per slide, density curve
- **CTA mechanic** — where the funnel hits, how soft/hard
- **Hashtag pattern** (if visible)
- **Engagement signals** (likes, saves, comments — if visible in screenshot)

## File naming hint (optional)

If you can name files something like `topic-platform-engagement.jpg` (e.g.
`anxious-attachment-instagram-3M-likes.jpg`), I can prioritize the
highest-converting ones. But not required — naming is your call.
